# 실습 자산 — AI 서비스 엔지니어링 10기 (블록 3·4)

**이 저장소는 직접 열어 볼 필요가 없습니다.** 수업 노트북이 알아서 받아 갑니다.

Colab에는 파일을 올릴 자리가 없어서, 노트북 첫 셀이 여기서 실습 재료를 내려받습니다.
여러분이 할 일은 노트북을 열고 위에서부터 실행하는 것뿐입니다.

## 무엇이 들어 있나

| 폴더 | 무엇 | 어느 주차에서 |
|---|---|---|
| `00_공통/` | 노트북이 함께 쓰는 도구상자 (OCR·검색·게이트) | 10~15주 |
| `assets/` | 실습 재료 — 명세서 사진, 약관 PDF, 공지 HTML, 시드 위키 20편 | 10~15주 |
| `노트북_보조/` | 노트북이 만들지 않고 미리 받아 두는 파일 2개 | 11·13주 |

명세서·계좌·카드번호는 전부 **가상 데이터**입니다. 실제 개인정보가 아닙니다.

## 강사용 메모

정본은 교안 패키지(`pkg/`)이고 이 저장소는 그 사본입니다. 자산을 고쳤다면
`pkg/` 쪽을 먼저 고치고 여기에 반영하세요. 거꾸로 하면 다음 빌드에서 덮입니다.

노트북이 `%%writefile` 로 만드는 파일(`tools.py`·`brain_flow.py`·`extensions/*.py` 등)은
여기 두지 않습니다. 학생이 수업 중 직접 만들어야 하는 것이기 때문입니다.
