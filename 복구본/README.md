# 복구본 — 막혔을 때만 쓰는 예비 부품

이 폴더의 파일은 **여러분이 수업에서 직접 만드는 것들**입니다.
그런데 앞 주차 노트북을 못 돌렸거나, Colab 런타임이 끊겨 파일이 사라지면
그다음 주 실습이 통째로 막힙니다. 그때를 위한 예비 부품입니다.

## 어떻게 동작하나

노트북 첫 셀이 이 폴더를 **찾는 자리 맨 뒤에** 놓습니다.

- 여러분이 만든 파일이 있으면 → 그것을 씁니다
- 없으면 → 이 폴더의 것을 씁니다. 그때는 화면에 그렇게 찍힙니다

그러니 이 폴더를 열어 볼 일은 없습니다. 그리고 **정답지가 아닙니다** —
수업에서 만드는 과정이 본론이고, 이건 다음 주가 막히지 않게 하는 안전망입니다.

| 파일 | 원래 만드는 곳 |
|---|---|
| `w10_vision_ingest.py` | W10D4 |
| `w11_embed_search.py` | W11D3 |
| `rag_v1.py` | W12D1 |
| `w12_chunks.py` | W12D2 |
| `tools.py` | W13D1 |
| `brain_flow.py` | W14D1 |
| `tracer.py` | W14D2 |

## 강사용 메모

이 파일들은 노트북 21개를 순차 실행한 산출물입니다. 빌더를 고쳤으면
노트북을 다시 돌려 여기도 갱신하세요. 손으로 고치면 노트북과 갈라집니다.
